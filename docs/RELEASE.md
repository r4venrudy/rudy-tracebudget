# Rudy TraceBudget 0.1.0 preview

Offline OTLP JSON trace inspection and latency budgets. Compare qualified root p95 by service and operation, inspect child interval coverage and concurrency, and separate trace topology problems from timing regressions.

The release contains self-contained Windows x64, Linux x64, and macOS ARM64 packages. Compare each archive against its entry in the SHA-256 manifest before extracting it.
